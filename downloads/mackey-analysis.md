의사결정·다양한 이해관계자·학교 지원의 기출 개념을 현재 디지털 도구 도입 사례에 적용한다.

기초 후보: core-governance-culture, core-teacher-development. 기출 근거: sec-2021, sec-2024, sec-2026.

학습 범위: 합리·점증 의사결정의 비교 / 구성원 참여 / 목적·비교안·제약 명시 / 대표성 / 사용성과 학습 효과의 구별 / 후속 수정의 근거 공개

**자체 제작 연습 문제**: 시연에서 성능이 좋아 모든 학급에 새 도구를 도입하려 한다. 합리모형과 점증모형의 적용 방법을 비교하고 학생·교사의 의견을 반영할 방안2가지를 설명하라.

- 답안 확인: 이론 정의와 학교 적용이 대응하는가
- 답안 확인: 찬성 의견만 모은 표본의 한계를 인식하는가
- 답안 확인: 작은 실증과 결과에 따른 수정 조건을 설명하는가

이는 공식 예상문제나 공개 정답이 아닌 자체 연습이다.

## 공부 앱에 적용할 학습 흐름

- 핵심 정의·이유·방법을 직접 적은 뒤 해설을 펼친다. 읽기 완료와 독립 인출을 구분한다.
- 답안을 보기 전 확신과 혼자 쓴 답안의 누락을 함께 기록한다. 메타인지 점검과 다음 학습 대상을 정한다.
- 해설을 본 직후 복사한 답과 다음 날 자료 없이 쓴 답을 따로 표시한다. AI 지원 수행을 독립 역량으로 합산하지 않는다.
- 기출 요구 충족 여부와 근거 문장·누락 항목을 피드백한다. 세부 공식 채점기준이 비공개이므로 확정 점수 대신 수정 행동을 남긴다.
- 피드백 뒤 다음 행동1개를 정하고 수정 답안을 작성한다. 피드백 전달이 실제 간극 축소로 이어지게 한다.
- 표준 이론명·공식 정책·저자 제안·분석자 연결을 각각 표시한다. 잠정 표현과 현재 제도를 사실처럼 섞어 암기하지 않게 한다.
- 정의 다음에는 이유·장점·방법·유의점을 학교 사례로 쓴다. 기출의 요구 행동을 연습한다.
- 요약과 쪽/장 위치, 사용자 로컬 원본 링크를 제공한다. 긴 원문을 다시 읽을 위치를 쉽게 찾는다.
- 초등과 중등의 원문 요구·답안 조건을 각 시험 기준으로 표시한다. 중등의 이론명 요구와 초등의 교직논술 맥락을 같은 정답 구조로 처리하지 않는다.

## 수정하거나 유보할 내용

- 교직실무 머리말의 2022 교육과정 적용 완료는 2027년 중3·고3 적용이 남아 있는 현재 시점에 맞게 수정한다.
- 인출 연습의 저부담 운영·표본10장·불일치3할·실증4~8주·협의체교사50% 등의 수치는 저자 맥락의 제안이며 보편 법칙이나 공식 기준이 아니다.
- 학습 선호 유형에 자료를 맞추면 학습이 향상된다는 주장의 근거 부족과, 2026 기출의 인지양식 개념 구분은 서로 다른 문제다. 인지양식 전체가 부정되었다고 암기하지 않는다.
- 구성주의적 비계와 오류 가능한 AI 도움을 똑같이 취급하지 않는다. 학생-교사/동료 상호작용의 가치도 별도로 설명한다.
- 교수 관점은 최근 논술 사례를 풍부하게 하지만 출제위원의 관점·출제 의도·2027 출제 확률을 입증하지 않는다.
- 교수설계 머리말의 교사 AI활용률62.9%·불안86.6%는 저자가 KICE 조사로 인용한 수치다. 보도에서는 확인되지만 공식 조사 원문은 미확보하여 이 분석의 확정 통계로 재사용하지 않는다.
- PDF와 HTML 모두 추출했으나 인용 참고문헌75개 전체의 결과·법령 조항 전체를 독립 감사한 것은 아니다.
- 기출 응용 문제의 답안 점검은 자체 제작 연습 기준이며 한국교육과정평가원의 비공개 공식 채점기준이 아니다.

원문 전체 텍스트는 연구용 로컬 파일이다. 사용자 보유 자료는 요약과 장/쪽 위치로 연결하고, 원문을 공개 사이트에 복제하는 자료로 사용하지 않는다.
